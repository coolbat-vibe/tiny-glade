# 《林间小世界 · Tiny Glade》— 治愈微缩建造物语 (v2 远山扩建与漫步工坊版)

100% 零外部依赖、支持**单文件断网离线双击运行**的 3D 治愈系微缩城堡与田园建造游戏。美术风格、程序化涌现机制与触觉操作反馈全面对标 *Tiny Glade（林间小世界）*，底层采用从零手写的 **WebGL2 (`#version 300 es`) 多通道 HDR 风格化渲染引擎**与**实时程序化建筑/地貌生成器**。

---

## 快速开始（单文件离线运行）

- **直接双击离线游玩**：在访达（Finder）或任意浏览器中直接打开 [`index.html`](./index.html)（`file://` 协议完全断网可用，零外部 CDN / 字体 / 贴图 / 音频请求）。
- **源码二次构建**：
  ```bash
  npm run build   # 将 src/* 编译打包为独立单文件 index.html 并执行语法与零外链校验
  npm start       # 可选：启动本地静态预览服务 http://127.0.0.1:8420
  ```

## v2 重磅升级：地图工坊、操作反馈与交互体验

1. **林间地图工坊（快捷键 `M`）— 无损扩建 & 自定义新地图**
   - **三级可建造幅员规格 + `±260m` 连绵远山天际线**：支持 `60×60m 微缩庭院`、`96×96m 广阔林谷（2.5倍面积）` 与 `136×136m 宏伟领地（5.1倍史诗疆域）`，外围无缝衔接远山田园缓坡与镜头自适应远景薄雾，彻底告别地图边缘悬崖截断与拉远雾化泛白。
   - **原地一键无损扩建**：在保留当前 **100% 已建房屋、石墙、拱门、池塘与小径**的前提下，直接将 `60m → 96m → 136m` 向外平滑延展山川林木，并完整支持 `Ctrl+Z` 撤销/重做！
   - **6 大自然地貌原型生成器**：自由选择 `牧羊林间空地`、`蜿蜒溪流河谷`、`镜湖星罗群岛`、`层叠山崖台地`、`双溪交汇芳洲`、`古堡遗迹秘境（自带青苔残垣与古井）`，并自定义初始季节、林木繁茂度、水系丰沛度与地形随机种子。
2. **微缩触觉操作反馈升级（Juicy & Tactile Feedback）**
   - **幽灵落点蓝图 + 实时尺寸胶囊**：建造方屋/圆塔前悬停地面（或屋顶露台叠建处）即可预览半透明暖光蓝图；拖拽生长时实时悬浮显示 `长 × 宽`、`叠层上筑`、`石墙长度` 等精确标尺。
   - **体积守恒弹簧果冻反馈 + 地面金色涟漪**：放置、涂色、复制或切换女墙/石拱时，建筑、石墙与装饰均触发阻尼简谐弹性形变（Squash & Stretch）与尘土粒子、竖琴木鱼声效。
   - **全实体统一选中与防重叠 3D 手柄**：不仅房屋支持 5 向手柄，**石墙/篱笆**现也支持选中调节 `⇕ 墙高` 与切换样式，**庭院装饰**支持选中拖拽平移、`↻ 旋转朝向` 与复制；所有悬浮手柄具备屏幕空间自动避让防重叠。
   - **涌现奇观悬浮提示 + 无级笔刷缩放**：首次触发开凿石拱门、花园木门、自动房门石阶或架设木桥时自动浮现庆祝徽章；支持滑块、`[` / `]` 或 `Shift + 滚轮` 无级缩放笔刷半径。
3. **村民第一人称漫步模式（快捷键 `G`）**
   - 随时化身林间村民，用 `WASD`（`Shift` 轻跑）亲自走过亲手建造的石板小径、高架石拱廊与水面木板桥，实时触发草地、石径与木桥三种材质的真实脚步声与视线微晃。
4. **精致水粉手绘 SVG 界面 & 6 槽位离线存档画廊**
   - 全套定制双色矢量 SVG 图标、可折叠微缩课题卡、点击画布自动收起弹窗、`Tab` 键一键隐藏全部 UI 纯净观赏，以及支持自定义命名的 **6 槽位浏览器离线存档画廊 + `.glade.json` 单文件导入导出**。

## 核心涌现式程序化机制（对标《林间小世界》）

- **小径 × 石墙 = 自动开凿 3D 楔石圆拱门**（木篱笆则自动敞开花园木门）。
- **小径 × 建筑墙根 = 自动生成拱形橡木门 + 自适应地形石阶 + 铁艺暖光壁灯 + 花盆**。
- **小径 × 清澈池塘 = 宽径自动架设带扶手木板桥，窄径自动铺设青苔汀步石**。
- **屋顶压低 = 自动变形为 3D 石质古堡垛口女墙**；屋顶继续拖拽可多层叠建高塔城堡。
- **底部石拱抬升 = 陆地自动生成石质拱廊桥墩，水面自动生成橡木栈桥木桩**。

## 自定义 WebGL2 六通道渲染管线

| 阶段 | 渲染通道 | 核心图形学特性 |
| :--- | :--- | :--- |
| **Pass 1** | 相机跟随太阳阴影贴图 (`2048×2048`) | 自适应缩放纹素对齐正交视锥 + 12-Tap 旋转 Vogel 盘软阴影 + 飘动云影 |
| **Pass 2** | 水面平面反射 (`Planar Reflection`) | 实时镜像渲染天空积云、城堡尖塔、金秋林木与夜间发光窗户 |
| **Pass 3** | HDR 主场景 MRT 通道 (`RGBA16F`) | 水粉风格化 PBR 光照、草木次表面散射、68,000 株 GPU 实例化草叶、6,800 朵实例化野花、`±260m` 远山天际线 |
| **Pass 4** | 屏幕空间环境光遮蔽 (`SSAO`) | 12 采样半球深度重建环境光遮蔽 + 深度感知双边滤波 |
| **Pass 5** | 多级 Dual-Kawase HDR 辉光 | 3 级降采样 + 升采样金字塔辉光，营造暖窗、灯笼、水面波光与萤火虫光晕 |
| **Pass 6** | 移轴景深与电影级色调映射 | 微缩沙盘移轴虚化（Tilt-Shift DoF）+ 暖调 ACES Filmic 色调映射 + 防色带抖动 |

## 目录结构

```text
tiny-glade/
├── index.html          # 编译后的独立单文件离线版游戏（直接双击可玩）
├── build.js            # 零依赖单文件离线打包器（含 VM 语法与零外链校验）
├── server.mjs          # 本地静态预览服务器
├── package.json
└── src/
    ├── template.html   # 游戏界面结构、地图工坊弹窗、漫步横幅与摄影棚 HUD
    ├── styles.css      # 暖色羊皮纸毛玻璃 UI 与定制矢量图标样式
    ├── math.js         # 矩阵/向量、射线检测、Catmull-Rom 样条与噪声内核
    ├── palettes.js     # 水粉配色、四季材质、三级地图规格、6大地貌与精选奇景预设
    ├── audio.js        # Web Audio API 程序化 ASMR 音效、弹性音效与脚步声引擎
    ├── geo.js          # 高速 TypedArray 网格构建器与吉卜力球面法线图元
    ├── terrain.js      # 多尺度高度场、无损扩建重采样、6大地貌生成与 ±260m 远山网格
    ├── procgen.js      # 程序化建筑、隅石、瓦片、弹性形变与拱门/木门/木桥涌现生成
    ├── nature.js       # 6.8万株实例化草叶/野花、外环扩建林木、绵羊/野鸭 AI 与粒子
    ├── shaders.js      # 全套 WebGL2 (#version 300 es) 多通道着色器与镜头自适应薄雾
    ├── renderer.js     # WebGL2 FBO/MRT/VAO 管线、动态地形纹理重分配与阴影跟随
    ├── game.js         # 核心状态机、地图工坊、村民漫步、弹性物理、统一手柄与存档
    └── ui.js           # 地图工坊面板、6槽位存档画廊、笔刷缩放与世界悬浮反馈同步
```
